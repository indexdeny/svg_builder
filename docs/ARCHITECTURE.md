# Актуальная архитектура SVG Builder

Дата: 2026-11-19. Область: дополнение v1.1 о whitelist.

## Владение данными

Фактические изображения находятся только в `01_input_raster/complex_gradients/`
и `01_input_raster/high_contrast/`. Эти пути заданы в SSOT
`00_governance/pipeline_config.json`. `reference-whitelist.json` — производный
реестр этого набора, а не альтернативный набор входов.

`reference_whitelist.py` отклоняет отсутствующий каталог, ошибку чтения,
symlink/reparse point, неканонический путь, несовпадение SHA-256 и устаревший реестр.
Полная сверка выполняется на входе этапа; отдельная запись повторно сверяется
по пути и фактическим байтам перед обработкой.

## Этапы

| Этап | Реализация | Результат |
|---|---|---|
| Инвентаризация | `reference_whitelist.py` | Канонический реестр и fingerprint |
| Деконструкция | `deconstruct.py`, `classify.py` | Raw JSON с путём и SHA-256 |
| Нормализация | `validate.py` | Schema-valid COMP JSON и Markdown паспорт |
| Векторизация | `compile_svg.py`, `hifi_vectorize.py`, `sketch_vectorize.py` | SVG с embedded contract |
| Экструзия | `compile_3mf.py` | Независимые cutout/raised и sidecars |
| Сверка | `validate_dataset.py` | Lineage, contracts, геометрия, orphan/link audit |

Raw-имя использует хеш канонического пути. Одинаковые basename в разных папках
остаются разными источниками. COMP ID стабилен при повторной нормализации
того же источника. Старые ID без доказанного хеша не переиспользовались:
текущие записи созданы заново из разрешённых байтов.

## Контракты и статусы

Паспорт указывает полный относительный путь и SHA-256. SVG повторяет эту
идентичность в embedded metadata и graph mirror. Sidecar 3MF указывает SHA-256
растра и source SVG, COMP ID, параметры масштаба и проверенные свойства mesh.
Дополнительные provenance-поля расширяют существующие схемы; исходные поля
контрактов и пороги качества сохранены.

Успешный SVG получает `compile_status=PASSED`; отказ — `QUARANTINED` или
`rejected_low_detail`. Неуспешный вариант 3MF получает диагностический
`.failure.json`, не имитирующий sidecar существующего binary. Эти diagnostics
публикуются вместе с набором для воспроизводимого объяснения отказов.

Валидация 3MF проверяет фактически повторно импортированный файл: watertight,
согласованность winding, положительный объём, габариты и явную единицу millimeter.
Проверка JSON отдельно не доказывает существование или корректность модели.

## Границы очистки

Автоматический clean ограничен явно выбранным `05_output_svg` либо
`07_output_3mf`; перед удалением проверяется весь набор путей и отсутствие ссылок
за границы каталога. Исходные изображения не меняются. Внутреннего архива нет.

Полный исходный Git bundle, рабочая папка, SHA-256 исключённых файлов и
исторический подробный аудит сохранены только во внешнем backup.
Публичная документация не перечисляет исключённые персональные файлы.

## Публичная воспроизводимость

Владелец подтвердил право публикации всех 56 разрешённых исходников и производных.
Публичный source dataset соответствует локальному whitelist по SHA-256.
Отдельный `smoke_check.py` воспроизводит полный путь на двух геометрических
fixtures во временной папке. Это тестовый набор, не результат проекта на
исходниках владельца.
