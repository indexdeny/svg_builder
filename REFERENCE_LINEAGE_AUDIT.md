# Аудит происхождения разрешённых референсов

Дата: 2026-11-19. Только фактические файлы двух разрешённых каталогов.

## Метод

В старых 124 COMP-записях отсутствовал проверяемый SHA-256 исходника. У 56
было совпадение basename с разрешённым файлом, но оно не использовалось как
доказательство происхождения. Старые записи и результаты исключены; все
56 текущих записей заново получены действующим pipeline из неизменных байтов.
Новые COMP ID исключают ошибочное наследование неподтверждённых связей.

Текущая цепочка: путь+SHA-256 растра → raw classification → schema-valid
COMP JSON → паспорт с тем же SHA-256 → embedded SVG metadata → eligibility →
source-SVG SHA-256 в mesh sidecar → фактически повторно импортированный 3MF.

Raw JSON регенерируется и не хранится в Git. Все 56 текущих raw-записей
сверены локально. Таблица включает только разрешённые исходники; названия
исключённых файлов и подробный исторический аудит остались во внешнем backup.

`PASSED` у SVG означает автоматические quality gates. `NOT_ELIGIBLE` у 3MF
означает запрет экструзии для SKETCH_VECTOR. `QUARANTINED` у варианта —
зафиксированный отказ геометрической проверки, а не существующий binary.
